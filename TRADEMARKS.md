# The ModWrench name and logo

ModWrench™ and the ModWrench logo are trademarks of Seanson, who maintains ModWrench. They aren't registered trademarks, which is why the mark is ™ and not ®.

ModWrench's code is under the [MIT license](LICENSE): you can use it, copy it, change it and share it, for any purpose, including commercially. The MIT license covers the code. It doesn't cover the name or the logo. This page says how you can use those.

## Why the name is kept to this project

People trust ModWrench because of the promises in [TRUST.md](TRUST.md): it never downloads or changes a mod, never stores your data, never sends anything to us, and asks before its one write. Each of those can be checked against this repository's code. A program that changes what ModWrench does could break any of them. If it carried the same name, people would assume it keeps the same promises. So the name ModWrench means this project, built from this repository.

## Fine without asking

- **Saying what's true.** "I use ModWrench", "works with ModWrench", "a ModWrench skin", a review, a tutorial, a video, an article, a forum post, a talk.
- **Pointing at it.** Naming ModWrench in an MCP client's settings, in lists, directories and registries of MCP servers, and in links to this repository, its website or its npm packages.
- **Sharing it unchanged.** Passing on ModWrench's own, unmodified packages under its name.
- **Saying where a fork came from.** "Based on ModWrench" or "a fork of ModWrench", with a link here.
- **The logo, unchanged,** in an article, a list or a link about ModWrench.

## Ask first

Open an [issue](https://github.com/171county/modwrench/issues) before using the name or the logo for any of these:

- a product, company, service, app, browser extension or website;
- a package name or npm scope, a domain name, or an account (a social handle, a Discord server) that could look official;
- merchandise;
- an event named after ModWrench.

## Not allowed

- **Calling a modified version ModWrench,** or anything that could be taken for it: "ModWrench Pro", "ModWrench Plus", "ModWrench AI", "Mod-Wrench", "ModWrench Enhanced".
- **Publishing under the `@modwrench` npm scope.** It belongs to this project.
- **Suggesting ModWrench or its maintainer made, endorses or sponsors something** they didn't.
- **Using the logo, changed or not, to stand for something else.**
- **Selling ModWrench itself as if it were an official paid edition.**

## Forks

Forks are welcome: that's what the MIT license is for. Give yours its own name and its own logo, and say it's "based on ModWrench" with a link here. Keep the ModWrench name off its package name, its app and its website title. A fork can change what the program does, and its users need to know they aren't running ModWrench, whose promises are in [TRUST.md](TRUST.md).
