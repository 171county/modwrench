# @modwrench/curseforge

**Status: scaffolded, not yet implemented.**

CurseForge has the largest catalog of any platform ModWrench will integrate — Minecraft + Sims 4 Mod Hub (via the 2022 EA partnership) + WoW + ARK. Overwolf-owned, which carries a trust deficit in some modder communities; ModWrench mitigates by adding Modrinth first so the positioning is "we serve users wherever the mods live" rather than "we're cozy with Overwolf."

See [ROADMAP.md](../../ROADMAP.md) for sequencing and the contribution path.
