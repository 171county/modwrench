Your AI's wrench for game mods.

Ask in plain words why your game crashed, whether it's safe to update, or why your mods keep breaking. ModWrench reads your crash logs and your setup on your own computer and gives your AI the facts to answer with.

  • Free and open source (MIT)
  • Runs on your machine
  • No account needed
  • Nothing sent to us, ever

Try it in your browser

Two of ModWrench's tools run right here, on this page, with the same tested code ModWrench ships. What you paste or pick stays in your browser: nothing is uploaded, and the page's own security policy forbids it from sending anything anywhere. There is no AI on this website. It lays out the facts the log holds; talking them through with you, and checking your install (the Doctors, Patch Day, finding your newest crash log on its own), need ModWrench installed.

Crash log reader

Paste a crash log from Crash Logger SSE, Buffout 4, NetScriptFramework or BepInEx, or choose its file. It reads the log the way Crash Whisperer does: what happened, the names the log points at and how strongly, and a help post for each place you might ask. Before anything reads the log, it takes out what it recognises as personal: folder paths (your user name in them goes too), a name after a label like USERNAME= or Computer Name: wherever else the log has it, network and email addresses, keys and account IDs. Installed, ModWrench also knows your account and computer name and looks for them everywhere. A web page can't know them, so here your name stays where it isn't in a path or after such a label. Read a post before you share it.

No crash log to hand? Try a sample log reads a made-up Skyrim crash from ModWrench's own tests.

Crew Check

For co-op nights on Thunderstore games: paste two or more crew lists to see who's missing which mod, and which mods are on different versions. From 0.3.0, ModWrench makes your crew list from your r2modman profile; until then you can write one by hand. It looks like this:

ModWrench crew list 1 · Lethal Company · 3 mods

It's yours. Here's what that means.

ModWrench runs on your computer. There is no ModWrench service and no server of ours for it to talk to. These promises are written down in full, with how to check each one yourself, on the trust page.

  • It never downloads, installs or deletes a mod.There is no download code in it.
  • It never changes your load order, your mods or your game files.Every local tool opens files read-only.
  • It never stores your data.Nothing is written to disk. What it reads lives in memory only until the answer reaches your AI.
  • It never sends anything to us.No analytics, no crash reporting, no telemetry. No network address in its code belongs to us.
  • One write action, and only when you say yes.It can endorse a mod on Nexus to credit its author. It shows you exactly what it will do first, every time.
  • It never rates or scores a mod.It tells you what a mod is. It doesn't review someone's work back at them.

Install: pick your app

You need Node.js 20 or newer, and an AI app that supports MCP and runs on the computer your games are on. Thunderstore and the local tools work straight away, with no account and no key. Each app's steps come from its own documentation (checked 2026-10-24). ModWrench has been run in Claude Code, Claude Desktop and Cline; in the others it hasn't been tried yet, so tell us how it goes.

Claude DesktopDraws ModWrench's pages
  1. Open Settings → Developer → Edit Config. That opens claude_desktop_config.json.
  2. Put this in it (if the file already has other servers, add the "modwrench" entry inside its "mcpServers"):
{
  "mcpServers": {
    "modwrench": {
      "command": "npx",
      "args": [
        "-y",
        "@modwrench/cli"
      ]
    }
  }
}

Quit Claude Desktop completely (from the icon by the clock, or the menu bar on a Mac) and open it again.

Claude CodeText answers

In a terminal, or in VS Code's terminal if you use the Claude Code extension:

claude mcp add --transport stdio --scope user modwrench -- npx -y @modwrench/cli

Then start a new conversation and run /mcp: ModWrench should say connected. On Windows, if its tools don't load, use cmd /c npx -y @modwrench/cli after the -- instead.

VS Code (Copilot Chat)Draws ModWrench's pages

Install in VS Code

VS Code asks you to confirm, then adds it. Or open the Command Palette (Ctrl+Shift+P), run MCP: Open User Configuration, and add:

{
  "servers": {
    "modwrench": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "@modwrench/cli"
      ]
    }
  }
}

Switch the chat to Agent mode. To see ModWrench's pages in the chat, turn on the experimental setting chat.mcp.apps.enabled.

CursorDraws ModWrench's pages

Add to Cursor

Cursor asks you to confirm, then adds it. If the button doesn't fill it in, add this to ~/.cursor/mcp.json yourself:

{
  "mcpServers": {
    "modwrench": {
      "command": "npx",
      "args": [
        "-y",
        "@modwrench/cli"
      ]
    }
  }
}
CodexText answers

In a terminal (the Codex CLI, IDE extension and desktop app share one configuration):

codex mcp add modwrench -- npx -y @modwrench/cli

Or add this to ~/.codex/config.toml:

[mcp_servers.modwrench]
command = "npx"
args = ["-y", "@modwrench/cli"]

On Windows, some people have needed command = "cmd" and args = ["/c", "npx", "-y", "@modwrench/cli"] instead.

Antigravity

In the agent panel's … menu: MCP Servers → Manage MCP Servers → View raw config, and add:

{
  "mcpServers": {
    "modwrench": {
      "command": "npx",
      "args": [
        "-y",
        "@modwrench/cli"
      ]
    }
  }
}
Devin

Devin on your computer (the Devin CLI, and Devin Desktop's local agent):

devin mcp add -s user modwrench -- npx -y @modwrench/cli

Devin in the cloud runs on its own virtual machine, so ModWrench there can't see the games on your PC. Searching mods works; reading your crash logs and setup doesn't.

Cline, Windsurf and other apps

Most apps that support MCP take this, in their MCP settings file:

{
  "mcpServers": {
    "modwrench": {
      "command": "npx",
      "args": [
        "-y",
        "@modwrench/cli"
      ]
    }
  }
}

Cline: MCP Servers → Configure. Windsurf's Cascade: ~/.codeium/windsurf/mcp_config.json.

Coding agents like Cline sometimes open a crash log themselves as well as asking ModWrench, which puts the raw log, with your folder names, in the chat. To keep it out, leave the app's approval for reading files on and decline that read, or ask it to "use ModWrench to read my crash log".

Then just ask: "Why did my game crash?"

Honest about where it is

Still being tested

  • Crash Whisperer's page has run inside Claude Desktop and the MCP Inspector on Windows. The other pages have only been tested against a stand-in for an AI app so far.
  • The newest tools haven't been run against a real game install yet. Testers on PC are welcome.

What it can't do

  • It can't promise a mod is safe to run. It shows what the platform records and what your files say.
  • It only knows the conflicts LOOT and the community have written down.
  • What it reads goes to your AI app. Where that goes is up to the app you use.
